## Rolling Summary

This task is long. Manage what you carry forward explicitly.

- Maintain a file `summary.md` holding only *confirmed* facts.
- Whenever you have accumulated several new confirmed facts, or a line of
  investigation closes, rewrite `summary.md` as a compact block of the current
  established state and drop the superseded detail.
- After a rewrite, reason from `summary.md` rather than from the earlier raw
  tool output. Re-read the raw source only when you need a detail the summary
  deliberately dropped.
- Never let a fact enter `summary.md` without a successful tool call behind it.
