## Working Notes

Maintain a file `notes.md` in your working directory for the whole run.

- Create it before your first substantive tool call.
- Every time you finish a subgoal, append one entry: what you set out to
  establish, the concrete result, and the tool call or file that produced it.
- Keep entries terse and factual. Do not restate the task, do not record
  intentions, only record settled outcomes.
- Before writing the final answer, re-read `notes.md` and make sure every claim
  in the answer traces back to an entry.
